或批量下载

一次修改多个文件时更方便
  1. 复制方式：选择对应文件，点击「复制此文件完整 JSON」，在 GitHub 打开同名文件 → 编辑 → 全选原内容 → 粘贴 → 提交。
  2. ZIP 方式：下载后先解压，按压缩包中的相对路径逐个上传/覆盖文件；不要直接上传 ZIP 文件。
  3. 新建的图库 JSON 文件不存在时，需先在 GitHub 创建该文件；提交到 main 分支后，GitHub Pages 才会更新。
  4. 刷新网站并检查图片，必要时按 Ctrl + Shift + R。
安全提示：本管理页面不会调用 GitHub 写入接口，也不会收集、保存或上传 GitHub 密钥。R18 仅是页面显示过滤，并不是私密图片访问控制。
